# Tribe of Abraham

A free, open source platform for music education tools, 
interactive learning apps, and maker hardware.

Built by musicians, educators, and craftspeople in 
rural Pennsylvania.

## Tools
- [Nashville Notation](../nashville-react) — 
Chord progressions in Nashville numbers, for guitar, bass and piano (React; built into notation/)
- [Drum Sequencer](../drum-sequencer) — 
Rhythm and subdivision explorer

## Hardware
- [MIDI Foot Pedal](../midi-foot-pedal) — 
Open source ESP32-S3 firmware for configurable MIDI controllers

## Philosophy
Everything here is free. The tools, the firmware, the code. 
Music and mathematics are the same conversation and everyone 
deserves access to that conversation.
