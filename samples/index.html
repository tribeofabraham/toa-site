Nashville Notation

My newest: a clean-slate React rebuild of my Nashville Number System tool. Pick a key on the wheel and see a progression of up to eight chords as numbers and names, with guitar or bass diagrams and piano keys, every note colored by its place in the chord. Chord types, presets, scales and transposing, spelled correctly in every key.

Everything is in relative units and scales itself to fill any screen, from a phone to a TV across the room. Checked with axe (no violations) and color contrast tested to 4.5:1.

React, WCAG, Music Theory, SVG, Responsive Scaling

Ragamuffin Telephone

Built for the McCulloch's Mills Historical Society. Pick up the line and Verna, the 1934 switchboard operator, puts you through to McCoysville in Pennsylvania's Juniata Valley. The characters, among them "vintage" versions of people who live in the valley today, know period-correct local history: researched with Claude Cowork, curated into a knowledge document and fed to ElevenLabs conversational AI, which speaks in each character's own voice. Standing responses cover the AI's thinking time, so the call never goes quiet.

Built in React with WCAG in mind: hold to talk by button or keyboard, a live transcript for screen readers, and scalable text. It runs the same characters as a working hardware telephone at Ragamuffin Hall, which falls back to a smaller local model when the internet is down. Sign in with your email to make a call.

React, WCAG, ElevenLabs, Conversational AI, Claude Cowork, Local History, Education

NCTM Pandemic

A remake of an app I built years ago with help from folks at NIH. It simulates Fauci's point that a few variables can greatly affect the outcome of a pandemic. Hit CALCULATE, then play: each run draws a new random set, charted as SVG in the DOM.

Letter Tiles

Requested to rebuild an existing tool but in a compliant fashion.

The bar for WCAG and ADA is much higher now in the academic community and they asked me to help them reimagine this tool as a compliant HTML5 asset.

Building an asset like this dynamically from JSON data allows me to address WCAG and accessibility issues as the asset is dropped in the DOM. Loading the tabs data from a JSON source allows the tile sets and instructional videos to be easily customized. There is a feature that allows an alternate tab set to be loaded via URL parameters.

EL Hub

Customer had a large collection of multilingual instructional material that they wanted to package and monetize to satisfy the growing demand for multilingual support in the public schools.

Unfortunately resources were quite limited at the time so we needed to get creative. We had a team of two to put the assets together and I had them organize the data using Excel spreadsheets which I used Python to injest into a JSON format. Python was generated with the help of AI and the entire operation is run offline via Jupyter Notebook.

HTML5, JSON, Streaming Media, WCAG, Multilingual, Python, AI
